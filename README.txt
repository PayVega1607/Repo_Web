GameVault — versión solo HTML y CSS

Archivos:
- index.html
- styles.css

No utiliza JavaScript, React, Vite, frameworks, fuentes externas, bibliotecas, imágenes externas ni recursos remotos. Las ilustraciones de las portadas están construidas con CSS.

Para probarlo:
1. Descarga y extrae el ZIP.
2. Abre index.html en el navegador.

La navegación entre Inicio, Tienda, Biblioteca y Perfil se hace con controles CSS (radio buttons ocultos y labels), y el diseño es responsive.

Importante: al ser estrictamente HTML y CSS, los filtros/búsqueda no procesan datos, y no se pueden ejecutar compras reales, guardar cambios, validar formularios dinámicamente ni editar la biblioteca. Para esas funciones hace falta JavaScript o un backend. Esta versión prioriza respetar el requisito de no usar nada externo ni JavaScript.
